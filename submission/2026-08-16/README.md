# Memury 初赛提交材料

本目录按《初赛提交材料》四项要求组织，可直接用于上传或评审。

1. `01_作品简介_500字内.txt`：必交，500 字以内。
2. `02_Memury_方案PPT.pdf`：必交，19 页 16:9 方案 PDF；同时附 HTML 版本。
3. `03_Memury_Demo_2m16s.mp4`：Demo 视频；说明见 `03_Demo与原型说明.md`。
4. `04_memury-canvas-upgrade-20260816.tar.gz`：可执行部署包；说明见 `04_可执行代码包说明.md`。

`SHA256SUMS` 用于校验所有二进制材料。在线体验：<https://canvas.memury.net/memury>。
