## 部署包

本目录附带 `04_memury-canvas-upgrade-20260816.tar.gz`。它包含依赖假设、配置、数据库迁移、Demo 样例数据、健康检查和回滚脚本。目标环境为 4 核 4 GB、已有 Docker Compose Canvas，默认 Canvas 根目录 `/opt/canvas-lms`。

```bash
shasum -a 256 -c SHA256SUMS
sudo mkdir -p /opt/memury-releases
sudo tar -xzf 04_memury-canvas-upgrade-20260816.tar.gz -C /opt/memury-releases
cd /opt/memury-releases/memury-canvas-20260816
sha256sum -c SHA256SUMS
chmod +x scripts/*.sh
sudo ./scripts/deploy.sh
sudo ./scripts/set-demo-password.sh
```
