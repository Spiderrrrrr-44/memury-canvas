# 三分钟 Demo 脚本

1. 以配置的测试学生登录 Canvas，从全局导航打开“Memury”，指出原型与 Demo 模式标识。
2. 点击“立即同步并重新规划”，展示 Canvas 来源和“模拟 SIS”课表/三天后考试；无需上传文件。
3. 阅读“下一最佳学习行动”的考试相关度、近期失败、36 小时 DDL 和预计 25 分钟理由。
4. 展示“概念诊断—完成作业—无提示检查与迁移”三个 Study Blocks，并完成或跳过一个块。
5. 开始诊断，故意选择“这两个力互相平衡”。系统先展示概念混淆/读题错误/计算失误三个候选，而非直接定论。
6. 回答最小验证问题，查看确认的错因与第 2 章“受力分析”引用；按需使用一级提示。
7. 完成电梯情境迁移题，查看掌握度变化、证据日志和剩余学习块重排理由。
8. 刷新页面确认状态保留；回到 Canvas 成绩页确认正式成绩未变化。
